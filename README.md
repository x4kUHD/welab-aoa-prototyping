# welab-aoa-prototyping

Static HTML prototypes for WeLab AOA feature work. No build step — plain HTML/CSS/JS per prototype.

## Structure

- `index.html` — links to all prototypes
- `shared/` — CSS/JS shared across prototypes
- `prototypes/<name>/index.html` — one folder per prototype; copy `prototypes/example` to start a new one

## Run locally

```
npm run dev
```

Serves the repo at http://localhost:3000.
